# Legal and regulatory risk signals for a four-country expansion.

Burgermeister Expansion Intel tracks legal and regulatory risk across the
United States, United Kingdom, Germany, and Poland for international market
entry, sorting signals by severity and flagging the ones that want outside
counsel.

**Live:** https://bm-intel-ivory.vercel.app

Note the deployment hostname: Vercel appended `-ivory` because the plain
name was taken, so `bm-intel.vercel.app` is not this project.
